About AI Resume Screening System

Project Overview

AI Resume Screening System is a web application that helps recruiters analyze resumes automatically using Artificial Intelligence. The system compares candidate skills with job requirements and provides a resume score for faster hiring decisions.

Main Features

📄 Resume Upload

Upload PDF or DOC resumes.

🤖 AI Analysis

Analyze skills and resume content.

📊 Resume Score

Generate skill match percentage.

👨‍💼 Admin Panel

Manage candidates and resumes.

Technologies Used

HTML5, CSS3, JavaScript, Python (Flask), Firebase Realtime Database, Machine Learning and Artificial Intelligence.
